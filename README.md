# Dental & Esthetic Art Clinic

Static HTML site configured for Netlify.

## Deploy on Netlify

1. Create a new site in Netlify and connect this repository, or drag this folder into Netlify Drop.
2. If connecting a repository, use the repository root as the base directory.
3. Leave the build command empty. Netlify publishes the root directory from `netlify.toml`.

The site entry point is `index.html` and local images are served from `img/`.
